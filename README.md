# API Testing Project

## Overview
This repository demonstrates API testing practices focused on REST services, business rules validation, and system integration scenarios.

The project simulates QA validation of CRM-style workflows and data synchronization between systems.

---

## Scope
- REST API validation
- Request and response verification
- Status code validation
- Business rules testing
- Data consistency checks
- Negative and edge case scenarios

---

## Testing Focus
- Functional API testing
- Integration testing
- Error handling validation
- Payload validation
- API response consistency

---

## Structure
- api-test-cases → API scenarios and validations
- bug-reports → API-related defects
- evidence → execution evidence and observations
- collections → Postman collections and requests

---

## Tools
- Postman
- REST APIs
- JSON
- GitHub
